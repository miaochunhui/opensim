# 公网同步交付

## 交付定义

用户要求产品更新必须同步公网。OpenSim 的对外交付地址固定为
`https://opensim.ai4everyone.top`。每次应用源码修改后，必须先完成
本地、浏览器及完整发布门，再部署固定版本，最后运行公网检查。
没有真实公网 PASS 就是未交付，不以本地通过、进程存在或健康200替代。
公网或第三方基础设施无法承诺永久零故障；必须可发现、通知并有恢复流程。

`tools/public_gate.py` 是同版本与真实计算判据的唯一实现：
正常验证 HTTPS 证书，禁代理/重定向绕回本地；核 DNS 公网地址、
五份运行源码完整 SHA256、页面构建、JS/CSS 字节；为每次观察生成新压差，
分别提交圆管和矩形管求解，与本地 FEM 的完整网格、节点速度、指标及
计算身份比较；检查求解时间及验证过程前后版本未漂移。
仅检查源码身份与有限元计算，不冒充网页可访问性或性能认证。

```bash
sudo -n -u infra python3 -B /data/dev/opensim/tools/public_gate.py
```

每次生成新 JSON/log，保留首因；失败退出1。输出在
`/hf3fs-jd/data/tmp/opensim-fluid-v1/public-gate/`。
测试中的 loopback PASS 显式为 LOCAL_TEST，不可能成为公网交付证明。

## 持续检查

`opensim-public-watch.timer` 每两分钟调用同一公网判据。专属进程运行为
infra，没有 DNS、证书、共享 edge 或服务重启权限，不执行代码同步，
不自动发布共享工作树中的在制品。故障首次出现通知，状态不变不刷屏，
真实检查恢复 PASS 发送不同标题的恢复通知。通知失败不推进已通知状态。
现役中继若回 `spooled`，状态明确为 QUEUED_NOT_DELIVERY_VERIFIED，
只证明中继接受并落盘，不证明邮件或用户收件。人工收件链仍须单独验收。
通知只使用既有 `/opt/notify/relay.token`，不改或输出凭据。
定时器不依赖聊天存活，但本机整体离线时本机巡检也不可用，未具备异地哨兵。

部署与回退只涉及两个专属 observer unit：
`deploy/opensim-public-watch.service` 和 `.timer`。
`tools/watch_install.py` 检查已有文件、完整字节、定时器受管状态；
回退只撤本次新增 unit，任何漂移先停，不改未知文件。
回退不删历史证据和通知状态。不重启 docs-site、gitlab-edge 或应用服务。
安装通过不代表公网通过；首次巡检与通知还要真实回读验证。

## 发布门与欠账

共享网页标准 shared-r41 的 G1 至 G6、真实触屏/软键盘、
桌面与移动屏幕阅读器烟测必须过门；确需临时例外，须明确规则ID、
原因、影响范围、负责人、到期日和移除条件，并由用户裁决。
不得因要求自动同步而默许未测项。上一轮浏览器报告
`release_verdict=NOT_CERTIFIED`，不能升格为认证。

当前结构提供同版本判据与只读巡检，**还不是自动发布系统**。
待关闭：首次 DNS/TLS/受管应用/共享edge最小发布；完整发布门；
固定release、验证后原子切换及恢复实证；证书安全续期回调；
获准发布链触发与异地巡检。任一未收，禁止声称“永远公网同步已保证”。
生产目标与最小回退边界见 `DEPLOYMENT.md`；不能盲跑其中已指出风险的旧工具。
