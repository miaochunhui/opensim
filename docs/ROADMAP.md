## 1. 固定截面可复现交付

只支持契约内圆形/矩形、无滑移壁面及参数范围；解析解只作独立参考，不填图代算。
算法保持现有标量 Poisson FEM，不加入入口、弯管、瞬态、湍流或全耦合。
验收门：同一 solver 身份复核圆管解析/矩形独立参考、三档网格收敛、流量、残差、
壁面与力平衡及非法输入；真实 HTTP/浏览器重算、脏参数拒用旧结果、导入重算和导出
均有证据。主席获授权后部署，另收线上真实求解与回退证据，才可称上线。

## 2. 复杂截面与几何契约

先确认 [接口提案](INTEGRATION.md) 的 mm/hash、修订和边界标签；复杂几何起点
仅为沿轴向不变的闭合截面（含孔），不是弯管或任意三维装配。
仍解标量 Poisson，但须更换/扩展几何导入与保边界网格器，处理孔洞、凹角和质量；
不能用 v1 圆/矩形网格器或插值结果冒充支持。
验收门：固定形状回归、单位/面积/边界往返、孔洞与坏几何拒绝、标签失效反例；
用独立参考或制造解核误差与加密收敛，凹角单列收敛规律。双方版本与联合证据齐备
后才开放 CAD 交换；复杂截面无证据时仍固定当前截面。

## 3. 混合 Stokes -> NS -> 3D（分门）

Stokes：从单个轴向标量改为速度向量与压力的混合 FEM 鞍点系统，明确压力基准；
设计选 inf-sup 稳定元（如 Taylor-Hood），或另证稳定化，不能照搬未稳定化等阶 P1。
过门须有制造解/直通道参考、速度压力收敛、散度/质量守恒及边界反例。

Navier-Stokes（NS）：再加入对流非线性，采用另行确认的 Picard/Newton 迭代与
线性预条件；若扩瞬态，另增时间离散与步长收敛门。先限定层流，核低 Re 的 Stokes
极限、独立基准、质量/动量残差和网格收敛；非收敛保留首因，不能输出伪成功。

3D：须真实体网格、三分量速度/压力空间及三维边界映射，重新验证混合系统与
线性/非线性策略；截面拉伸显示不是 3D 求解。先核直管极限与制造解，再核单独约定
的入口/弯管参考、体网格质量和加密收敛。每个子门独立通过，不从前一门外推支持。

## 4. 黑箱寻优与按域扩展

先取得 openopt 范围回执、失败语义与版本共识，初始寻优仍固定截面，不等待或默认
启用第三阶段。优化是外层有界黑箱候选策略，内层仍为获验收物理求解器；
无梯度问题不等于 LP/QP，算法由 openopt 提案并实测，不在 OpenSim 复制维护。
验收门：已知解目标/约束夹具、确定性失败、预算与取消断言，再接固定截面泵功率案例；
独立重算最终可行解、核约束和目标改进，保留轨迹与几何/网格/求解身份，不承诺全局最优。
之后才提改几何寻优，须先过第二阶段重建/边界失效门；3D 寻优还须过第三阶段。
机械需另选弹性向量 FEM 并验刚体模态/力能平衡；热管理需导热或对流扩散离散及热平衡；
EMC 需另立 Maxwell 模型、适用的边元/边界与解析或独立基准。各域另立契约、数值门，
耦合另验交换量与守恒，不能把流体 PASS 或外层优化成功推广为四域通过。
