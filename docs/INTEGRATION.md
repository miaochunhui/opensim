# 协作接口与迭代需求

2026-10-10；工作交接提案，不是接口共识、施工授权或已集成声明。

## 范围与当前入口

OpenSim 负责物理模型、网格、FEM 求解、验证和复现记录；OpenCAD 候选职责是
参数化几何与交换；openopt 候选职责是优化候选点及停止策略。OpenSim 不另做 CAD
或优化器，不修改两仓代码。当前只固定圆形/矩形直管横截面 2.5D，不接任意 CAD。
kernel 已真实实现、独立数值 PASS，但未上线；证据与后续门见 [路线](ROADMAP.md)。

v1 以 [CONTRACT](CONTRACT.md) 为准：输入长度为 mm，压力 Pa，黏度 Pa s；
内核换算到 SI，结果节点为 `nodes_mm`、速度为 m/s。只接受契约列出的 config 键。
`boundary_nodes` 仅代表横截面无滑移壁面；轴向入口/出口不是此模型的独立求解边界。
下述 hash、标签及外部评估字段均为迭代提案，不向 v1 HTTP 偷加字段。

## 几何身份与 OpenCAD

拟先以版本化文件清单交换固定截面描述，再讨论 STEP 精确实体；预览三角网格
不能冒充精确几何。文件清单与 v1 config 分离，升级契约后才开放导入。

| 需求 | 最小接口与验收门（均 PROPOSED） |
|---|---|
| 几何 mm/hash；OSIM-CAD-001 | 清单含 schema、模型/修订、单位、坐标系、参数和来源；`file_sha256` 校验原文件，另定规范化几何内容 hash 的生成规则/版本。mm/m 往返核尺寸，固定截面核面积与长度；实体阶段再核体积、重复实例及变换。未知单位、摘要不符、坏文件或空实体显式失败。 |
| 边界标签；OSIM-CAD-002 | 标签绑定几何修订/hash 和实际边/面引用；当前只有 wall 角色，角色与 OpenSim 物理条件分开。改参映射区分保持、拆分、合并、丢失、歧义；丢失、歧义及任何未确认拆并阻止复用旧边界。验收包含保持与删除/改孔/拆并误绑反例，复核实际空间位置。 |
| 改参重建；OSIM-CAD-003 | 声明变量类型、单位、范围，输出带父修订、生成器版本和参数的新修订；失败保留原模型。先测固定截面尺寸变化和坏参数；不同几何/网格/求解配置不得复用旧评估。取消或批处理未支持就明确拒绝。 |

容差、内容身份定义和样例由两方测试前确认；当前不要求解决任意拓扑命名、
装配、多物理边界或复杂截面导入。几何扩展必须先过路线第二阶段。

## openopt 黑箱评估

OSIM-OPT-001 的通用 LP/QP 是独立数值接口提案，不等于任意仿真寻优。
只读现有入口仍为组合优化兼容 API，通用 `minimize` 尚未实现，许可待权利人裁决。
OSIM-OPT-002/003 须先由 openopt 确认黑箱/非线性范围，不包装 QP 充当该能力。

拟议首个黑箱夹具保持截面与网格不变，只调契约范围内的压差；
最小化泵功率 `pressure_pa * flow_rate_m3_s`（W），约束
`Q_min - flow_rate_m3_s <= 0`、`reynolds - 2000 <= 0`，其余输入固定。
先核存在可行域，梯度默认不可用；目标、约束单位/缩放及方向须显式约定。

请求含版本、变量界、预算、种子、取消和终止规则；每次评估带 request/evaluation ID，
几何 hash、边界版本、完整 config、网格与求解器身份。OpenSim 负责评估与资源管理，
openopt 负责候选点、算法和停止策略，不派私池或自动申请 GPU。
成功记录有限目标与约束残差；失败记录首因、失败状态和显式缺失值，不能填 0/NaN。
区分可行未证最优、不可行、预算耗尽、取消、数值故障、不支持；适用时另列无界/最优证明。
验收先用已知解解析黑箱与确定性失败样本，再做固定截面夹具；断言预算不超限、
取消后不再派点、失败不算优解，并以独立重算和网格加密核最终可行性，不声称全局最优。
